### Assessment

The RFC cites **only** Aumann-Serrano [AS2008] for the entire mathematical framework. This is like citing a 2008 survey paper for the definition of a derivative while omitting Newton and Leibniz. The foundational concepts (SSD, martingale theory, almost sure convergence, risk-neutral measure) are each 30–70 years older than the cited source.

**Aumann-Serrano [AS2008] relationship to SSD**: The Aumann-Serrano index is *monotonic with respect to* SSD — it is consistent with SSD rankings but is NOT the original formalization of SSD. It provides a scalar riskiness index, not the dominance relation itself. The RFC's text "as formalized by Aumann and Serrano" is **incorrect**: SSD was formalized by Hadar-Russell (1969) and Rothschild-Stiglitz (1970). Aumann-Serrano built upon this earlier work.

## 2. Derivation Completeness Assessment

### 2.1 The MAS Definition (as stated)

```
E[L(V_{n+1})] = E[L(V_n)]  AND  F_{V_{n+1}} SSD F_{V_n}
```

where L is the loss random variable and SSD is Second-order Stochastic Dominance.

### 2.2 Missing Derivation Steps

#### Step Gap 1: What is the probability space?

**Problem**: The definition refers to $F_{V_n}$ (the CDF of the loss distribution under version $V_n$) but never defines:
- The sample space $\Omega$ (what are the elementary outcomes?)
- The $\sigma$-algebra $\mathcal{F}$ (what are the measurable events?)
- The probability measure $P$ (what assigns probabilities?)

**Why this matters**: SSD is a relation between CDFs. Without defining the probability space, the CDFs $F_{V_n}$ are undefined objects. A reviewer will ask: "Loss distribution *over what*? Over all possible agent behaviors? Over all possible network conditions? Over adversary strategies?"

**Fix**: Define $\Omega$ as the set of all possible agent behavioral sequences, $\mathcal{F}$ as the natural filtration generated by the state machine transitions, and $P$ as the physical (real-world) probability measure over agent behaviors.

#### Step Gap 2: "Branch elimination implies SSD" — UNPROVEN

**Problem**: The RFC claims:

> "if V_new eliminates one or more behavioral branches from the agent probability space while maintaining E[L], then F_{V_new} SSD F_{V_old}"

This is the central claim and it is **stated without proof**. It is also **not obviously true**.

**Analysis**: By Rothschild-Stiglitz (1970), when two distributions have the same mean, $F$ SSD $G$ if and only if $G$ is a mean-preserving spread of $F$. The claim asserts that "eliminating branches" is equivalent to a mean-preserving contraction. But:

1. **Branch elimination changes the support**: Removing branches changes the domain of the loss distribution. This is NOT the same as a mean-preserving contraction unless the probability mass of eliminated branches is redistributed in a specific way.

2. **Counter-example**: Suppose $V_{old}$ has three branches with losses $\{0, 1, 2\}$ with probabilities $\{0.5, 0.25, 0.25\}$, giving $E[L] = 0.75$. If $V_{new}$ eliminates the branch with loss $0$ and redistributes to $\{1, 2\}$ with probabilities $\{0.5, 0.5\}$, then $E[L] = 1.5 \neq 0.75$. To maintain $E[L] = 0.75$, we'd need different weights. The point is: branch elimination does NOT automatically preserve the mean, and even when it does, the resulting redistribution may NOT satisfy SSD.

3. **Correct statement would be**: "If $V_{new}$ eliminates branches whose loss values are at the tails of the distribution, and redistributes their probability mass to branches with loss values closer to the mean, then $F_{V_{new}}$ may SSD $F_{V_{old}}$." But this requires case-by-case verification, not a blanket claim.

**Fix**: Either (a) provide a formal proof for the specific class of branch eliminations that SASS performs, showing exactly how the probability redistribution satisfies the SSD integral condition, or (b) weaken the claim to state that each version upgrade is *conjectured* to achieve SSD and must be verified individually.

#### Step Gap 3: The equal-mean requirement

**Problem**: SSD alone does NOT require equal means. SSD is a partial order that can hold even when $E[L(V_{n+1})] < E[L(V_n)]$. The RFC adds the constraint $E[L(V_{n+1})] = E[L(V_n)]$, which converts SSD into the mean-preserving contraction equivalence of Rothschild-Stiglitz.

**Question**: WHY require equal expected loss? If $V_{new}$ actually reduces expected loss, that's strictly better. The equal-mean constraint seems artificially restrictive.

**Possible justification**: The authors may intend this as a conservative claim — "even if expected loss is unchanged, the distribution is improved." This is valid as a design choice but should be explicitly motivated.

**Fix**: Add a note explaining that the equal-mean constraint is intentional (conservative claim) and that the result is stronger when $E[L(V_{n+1})] \leq E[L(V_n)]$ with SSD.

### 2.3 "Almost Surely under Martingale Measure"

**Problem**: The RFC states:

> "'Almost Surely' is defined under the Martingale measure (equivalently, the risk-neutral q-measure), following the stochastic process framework of Itô calculus."

This sentence conflates **four distinct mathematical concepts** in a way that is at best imprecise, and at worst meaningless in context:

1. **"Almost Surely"** ($P(A) = 1$): A property of events under a specific probability measure. It is a mode of convergence (Kolmogorov, 1933). It has meaning only relative to a specified measure.

2. **"Martingale measure"** (equivalent martingale measure, EMM): A probability measure $\mathbb{Q}$ equivalent to the physical measure $\mathbb{P}$ under which discounted price processes are martingales (Harrison-Kreps, 1979). This is a concept from **mathematical finance**.

3. **"Risk-neutral q-measure"**: Same as the equivalent martingale measure. The $\mathbb{Q}$-measure exists if and only if the market is arbitrage-free (First Fundamental Theorem of Asset Pricing).

4. **"Itô calculus"**: A framework for integration with respect to semimartingales (Itô, 1944). Relevant for continuous-time stochastic processes driven by Brownian motion.

**The core confusion**: The RFC uses "Almost Surely" in its name (MAS = "Martingale Almost-Surely Superior") but the actual definition uses SSD — a comparison of CDFs. These are different concepts:

- **Almost sure convergence**: $P(\lim_{n \to \infty} X_n = X) = 1$ — a statement about the limiting behavior of a sequence.
- **SSD**: $\int_{-\infty}^{x} F(t) dt \leq \int_{-\infty}^{x} G(t) dt$ for all $x$ — a comparison of two distributions at a single time.

The MAS definition does not use almost sure convergence anywhere. The definition is purely about SSD between consecutive versions, with no limiting process, no martingale structure, and no stochastic calculus.

**Why the Martingale/Itô reference is problematic**:

- There is no continuous-time stochastic process in the protocol model. Versions are discrete ($V_1, V_2, \ldots$), not driven by Brownian motion.
- There is no financial market, no asset pricing, and no arbitrage argument. The risk-neutral $\mathbb{Q}$-measure has no natural interpretation in a protocol security context.
- Doob's Martingale Convergence Theorem (which connects martingales to a.s. convergence) requires $L^1$-boundedness: $\sup_n E[|X_n|] < \infty$. This condition is not checked or stated.
- If the authors intend the *sequence* of safety levels $\{S_n\}$ to form a supermartingale ($E[S_{n+1} | \mathcal{F}_n] \leq S_n$), as suggested in the AISec paper outline, then this is a **different claim** from SSD and requires a completely separate proof.

**Fix**: Choose ONE of the following frameworks and use it consistently:

- **Option A (SSD only)**: Drop all references to Martingale, Itô, and risk-neutral measures. Rename to something like "SASS Stochastic Dominance Superiority" (SSDS). Define purely in terms of SSD between consecutive version CDFs. This is the honest characterization of what the current definition actually states.

- **Option B (Supermartingale)**: If you genuinely want the Martingale structure, define $S_n = E[L(V_n) | \mathcal{F}_n]$ and PROVE that $\{S_n\}$ is a supermartingale. Then invoke Doob's convergence theorem (verifying $L^1$-boundedness) to obtain almost sure convergence. This is a much stronger claim and requires substantial additional work.

- **Option C (Hybrid)**: Keep the SSD definition as the primary claim. Add a separate theorem showing that, as a consequence of version-over-version SSD improvement, the sequence of loss distributions converges in some meaningful sense. This requires careful measure-theoretic setup.

### 2.4 "Equivalently, the risk-neutral q-measure"

**Problem in protocol context**: The risk-neutral measure $\mathbb{Q}$ is defined in the context of no-arbitrage pricing in financial markets (Harrison-Kreps, 1979; Harrison-Pliska, 1981). In financial mathematics:

- The physical measure $\mathbb{P}$ describes real-world probabilities.
- The risk-neutral measure $\mathbb{Q}$ is an artificial measure under which asset prices are martingales.
- The equivalence ($\mathbb{P} \sim \mathbb{Q}$) means they agree on null sets.

In a **protocol security** context:
- What is the "market"? (There is no traded asset.)
- What is the "no-arbitrage" condition? (There is no financial arbitrage in protocol version comparison.)
- What does "risk-neutral" mean for an operator evaluating protocol safety?

The concept is NOT well-defined in this context without substantial additional theoretical groundwork establishing an analogy between protocol version comparison and asset pricing.

**Fix**: Remove the parenthetical "(equivalently, the risk-neutral q-measure)" entirely. If a financial-analogy interpretation is desired, it must be developed as a separate theoretical contribution with explicit definitions.

## 4. Recommended v2 Revision

### 4.1 Rename

**Current**: MAS (Martingale Almost-Surely Superior)  
**Recommended**: **SASS-SD** (SASS Stochastic Dominance) or simply "Version Dominance Claim"

Rationale: The definition uses SSD, not martingale theory. Using "Martingale" and "Almost-Surely" in the name when neither concept appears in the definition is indefensible under peer review.

If the authors wish to keep the Martingale structure, they must develop it fully (see §2.3 Option B). This is substantial additional theoretical work.

### 4.2 Revised Definition (LaTeX)

```latex
\subsection{Version Dominance Claim}

Let $(\Omega, \mathcal{F}, P)$ be a probability space where $\Omega$ is
the set of all possible agent behavioral sequences, $\mathcal{F}$ is the
Borel $\sigma$-algebra generated by the state machine transition events,
and $P$ is the physical probability measure over agent behaviors.

For each protocol version $V_n$, let $L_n : \Omega \to [0, M]$ be the
bounded loss random variable with $M < \infty$, and let $F_n$ denote
the cumulative distribution function of $L_n$.

\begin{definition}[Version Dominance]
Protocol version $V_{n+1}$ \emph{dominates} $V_n$ in the sense of
Second-order Stochastic Dominance (SSD) if:
\begin{equation}
  \int_{-\infty}^{x} F_{n+1}(t) \, dt \leq \int_{-\infty}^{x} F_n(t) \, dt
  \quad \text{for all } x \in \mathbb{R}
\end{equation}
with strict inequality for at least one $x$.
\end{definition}

This is equivalent, by the theorem of Rothschild and Stiglitz
\cite{RS1970}, to:
\begin{enumerate}
  \item Every risk-averse operator (i.e., operator with concave utility
        function) weakly prefers $V_{n+1}$ over $V_n$.
  \item When $E[L_{n+1}] = E[L_n]$, the loss distribution of $V_n$ is a
        mean-preserving spread of $V_{n+1}$.
\end{enumerate}

\begin{remark}
If additionally $E[L_{n+1}] \leq E[L_n]$ (the new version reduces
expected loss), then the dominance holds a fortiori, as SSD is a
partial order that permits mean improvement.
\end{remark}

Implementations claiming Version Dominance compliance MUST demonstrate,
for each behavioral branch eliminated in the new version, that the
resulting redistribution of probability mass satisfies the integral
condition above. Specifically:

\begin{theorem}[Branch Elimination Sufficiency]
Let $B \subset \Omega$ be a set of behavioral branches eliminated in
$V_{n+1}$ with $P(B) > 0$. If the loss values on $B$ satisfy
$L(\omega) \geq E[L_n]$ for all $\omega \in B$ (i.e., the eliminated
branches have above-average loss), and the probability mass $P(B)$ is
redistributed uniformly to branches with $L(\omega) \leq E[L_n]$, then
$F_{n+1}$ SSD $F_n$.
\end{theorem}

This theorem formalizes the intuition that ``eliminating bad branches
makes the protocol better.'' The key condition is that eliminated
branches must have above-average loss; eliminating low-loss branches
would WORSEN the distribution.
```

## Appendix: SSD Preconditions Checklist

For the SSD comparison to be well-defined, the following conditions must hold:

- [ ] $E[|L_n|] < \infty$ for all $n$ (integrability)
- [ ] Loss distributions have well-defined CDFs (measurability)
- [ ] If bounded support is assumed, state the bounds explicitly
- [ ] The comparison is performed under the SAME probability measure
- [ ] If the measure changes between versions (e.g., due to changing attacker behavior), this must be addressed

Currently, NONE of these are stated in the RFC.
