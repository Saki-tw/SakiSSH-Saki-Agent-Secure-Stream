## 概述

本文提取自 SASS v2.0 GeminiVersion 概念實作中的五個核心 Plugin 增城版設計差異。這些概念代碼**不進入 production**（需完整測試），但其設計理念可作為 v2.0 開發時的參考。

---

## 1. ChaCha20 認知挑戰（challenge_store）

### v1.4 現狀
- 靜態金鑰，無過期機制

### v2.0 概念改進
- **Epoch 金鑰輪轉**：引入 `KeyEpoch` 結構，每個金鑰有 `created_at` 和 `expires_at`，防止金鑰疲勞與長期側信道洩漏
- **Constant-time 驗證**：預防 timing side-channel 攻擊
- **60s TTL 清理**：定時垃圾回收過期挑戰

---

## 2. 焦油坑（tarpit）

### v1.4 現狀
- 固定速率慢速串流

### v2.0 概念改進
- **Token Bucket 字節級流量整形**：強制限速至 256 bytes/s，精確控制發送速率
- **防 Window-Clamp 攻擊**：解決惡意 Agent 通過 TCP 零視窗/滑動視窗卡死鎖死 SASS 線程的側信道逃逸
- **全域靜態 64KiB 高熵 Buffer**：`STATIC_ENTROPY: OnceLock<Vec<u8>>`，共享實現 O(1) 空間複雜度
- **Host DoS 自吞噬防護**：全域並行計數器 + 寫入 chunk 的 send timeout

---

## 3. 分支管理（branch_mgr）

### v1.4 現狀
- 基本路徑隔離，無實時驗證

### v2.0 概念改進
- **Safe Path Resolution Guard**：利用 `realpath` (Unix) / `GetFinalPathNameByHandle` (Windows) 實時比對
- **防 Symlink Race**：`canonicalize()` 解析所有階層的實體 symlink 與相對路徑
- **防 ToCToU 攻擊**：高頻蜜罐逃逸與漏洞劫持防禦
- 確保解析後的實體路徑完全限制在 Branch 邊界之內

---

## 4. 環境注入（env_injector）

### v1.4 現狀
- 統一清洗，無 OS 區分

### v2.0 概念改進
- **OS-Aware 平台 Profile**：針對 Windows 動態保留 `SYSTEMROOT`、`SYSTEMDRIVE` 等核心系統變數
- **PATH 保全**：根治過度清洗 PATH 導致 `vcruntime140.dll` 遺失靜默崩潰的缺陷
- **I/O 減量快取重導向**：
  - Node/Yarn/Pnpm → 揮發性 RAM 快取
  - Rust/Cargo → 揮發性 RAM build target

---

## 5. 審計日誌（audit）

### v1.4 現狀
- 單一本地簽章

### v2.0 概念改進
- **雙重簽章防護**（Dual-Attestation & Ledger Anchor）：
  - 本地 `ed25519_dalek` 簽章
  - 外部飛地/時間戳節點的證書鏈證章（`enclave_attestation: Option<String>`）
- **防回溯偽造**：解決本地私鑰 `.pem` 被 Root 級入侵者竊取後可重新簽名偽造日誌的缺陷
- **結構化事件類型**：
  - `AuthSuccess`：含 agent_name, session_id, public_key_hex
  - `AuthFailure`：含 agent_name, reason, remote_addr
  - `CommandExecute`：含完整命令、參數、cwd、允許/拒絕理由
  - `FileOperation`：含操作類型、路徑、允許/拒絕理由
